# Changelog

## 1.2.0

- Formulas in markdown tables, in Reading view and Live Preview (`formula.ts`, `tables.ts`).
- Whole-column and whole-row ranges ignore the formula's own cell.

## 1.1.0

Fixes to the original 1.0.1:

- Works on mobile (`isDesktopOnly: false`).
- Opening and closing a sheet without editing no longer saves an empty file over it.
- Switching files in the same tab no longer writes the previous sheet's data into the new file.
- Unreadable files show an error instead of crashing, and are never overwritten.
- Saving keeps all sheet settings (frozen rows, filters, images, order), only the cell matrix is compacted.
- React root and resize observer are cleaned up on reload and close (memory leak).
- "New spreadsheet" in the file menu only appears on folders, no longer creates a folder named after a file.
- Added a "New spreadsheet" command.
- Upgraded FortuneSheet 0.19 to 1.0.4, which fixes context menu placement. Removed the CSS offset hack and the hand-copied stale CSS, `styles.css` is now generated by the build.
- The sheet fills the pane instead of a fixed `100vh - 130px` box.
- Upgraded build tooling (esbuild 0.28, TypeScript 5, strict mode) and added tests.
